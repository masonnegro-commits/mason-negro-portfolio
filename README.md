# Mason Negro Portfolio

A responsive, single-page portfolio site for an Ithaca College Economics student and wrestler.

## Preview

Open `index.html` in a browser. Google Fonts are loaded from Google Fonts when a network connection is available, with system font fallbacks.

## Personalize before publishing

Replace the highlighted bracketed placeholders with details you confirm. The brief marks proposed skills as unconfirmed and requests additional biography details. Confirm the contact email and add a LinkedIn URL only if desired. Add only real images and project information.
